## Overview

A personal portfolio designed from scratch in Figma and built with Astro as a static site. The design concept draws from vintage newspapers: sepia tones, grain textures, and typography reminiscent of early 20th-century print.

## Design Process

The visual identity was built around three pillars:

- **Newspaper aesthetic**: heavy headers, horizontal rules, column-based layouts
- **Warm palette**: sepia browns and cream backgrounds
- **Typography**: Nova Round for headlines, Rosario for body text, Libre Barcode 39 for decorative elements

## Technical Implementation

Built with Astro for maximum performance:

- Static site generation with zero JavaScript by default
- CSS-only grain texture overlay using pseudo-elements and blend modes
- Responsive design from mobile to desktop
- View Transitions API for smooth page navigation
